# 激活码生成器 · 使用说明

厂商侧工具：签发激活码、管理台账、删除（撤销）激活码。私钥只保存在本机。

| 页签 | 用途 |
|---|---|
| **签发** | 选私钥 → 填参数 → 生成激活码 |
| **管理** | 台账、使用状态、删除并失效 |
| **使用说明** | 本页 |

顶部一行是**中继服务器地址 + 中继令牌**：两个都能直接改，改完立刻生效；令牌是明文框（勾「隐藏」可打码），点「读取令牌」可从本机文件里读。

---

## 一、签发

### 1. 厂商密钥

- 私钥默认放在 `E:\RemoteControl\license\private.pem`，**绝不外发、务必自行备份**。
- 私钥丢了就再也签不出码（已发出的码不受影响，它们靠公钥验证）。
- 换新密钥对之后，**必须**把新公钥填进中继与被控端的源码并重新编译发布，
  否则新旧两套验签对不上：旧的码失效、新的码没人认。

### 2. 签发参数

| 参数 | 说明 |
|---|---|
| 授权编号 | 你的订单号/客户号，会显示在服务器 `/admin` 与主控端界面上 |
| 客户/备注 | 写给自己看的（谁在用） |
| 绑定部署ID | 从服务器读出来的 `DEP-xxxxxxxxxxxx`，**填了就只能装在这台服务器上** |
| 绑定公网IP | 可选，再上一道锁；客户出口 IP 会变的话别填 |
| 生效 / 到期日期 | **按 UTC 解释**（服务器与被控端都按 UTC 判定时间窗） |
| 最大主控端数 | 预留参数，当前版本不限制（填 0 也可） |
| 中继服务器 | `IP:端口`，启动时会自动去读它的部署ID与授权状态 |

> **关于日期用 UTC**：中继的 `/admin` 页面、被控端的日志、服务器上的判定全是 UTC。
> 界面统一用 UTC，你在这边看到的日期就和服务器上看到的一致，不会再差 8 小时。
> 到期日当天仍然有效（到当天 23:59:59 UTC 为止）。

### 3. 生成与安装

1. 点「**生成激活码**」，窗口下方会显示一整行 `RC1.xxxx.xxxx` 的码（并自动记进台账）。
2. **直接点「安装到服务器」**（推荐）：工具用「中继令牌」把这条码装到「中继服务器」上，
   装完立刻生效，被控端 60 秒内自动恢复 —— 不用再复制到浏览器里粘贴。
   若没填令牌，就改用下面的手动方式：
3. 点「**复制**」。
4. 点「**复制链接**」，把「安装入口」那条链接（自带令牌）粘到浏览器打开 ——
   `http://<中继服务器>:8080/admin?token=<中继令牌>`，把码粘进去点「安装 / 续期」；
   也可以在服务器上执行：

   ```bash
   /opt/rcserver/rcctl install "RC1.xxxx.xxxx"
   ```

5. 装好后中继立即恢复可用，被控端/主控端**60 秒内自动重连**，不用人工重启。
6. 「保存到文件」会把参数与安装步骤写成一份 txt，适合存档或发给客户。

### 4. 验证激活码

把客户手里的码粘进「④ 验证激活码」，点「验证」：
会显示是不是本厂商签发、绑定了谁、有效期到什么时候、还剩多少天。
签发后工具自己也会立刻自检一遍，自检不通过会在状态栏报警。

## 二、管理

### 台账怎么看

- 每签一条自动记一条，**存在私钥旁边**的 `license-history.json` 里，
  换台机器、换份 exe 打开都是同一本账（跟着私钥备份即可）。
- **状态**列的含义：

| 状态 | 含义 |
|---|---|
| 使用中 | 服务器上装的就是这一条（按指纹精确比对，不是猜） |
| 曾使用 | 这条以前装过，现在服务器上换成了别的码（续期了） |
| 未使用 | 签发后从未装到服务器上 |
| 已过期 | 已过了到期时间 |
| 已删除（已失效） | 你删掉了它：客户那边会停机，且装不回来 |

### 删除一条激活码 = 让它彻底失效

点选一行 → 「**删除并失效**」。会发生两件事：

1. 本地台账把它标记为「已删除」，默认列表里就不再显示（勾「显示已删除」可回看）；
2. 这一条的指纹被推送到中继的撤销名单，中继随之：

   - **正在装着的**：立即判为 `revoked`，拒绝一切通信，并主动通知在线被控端停机
     （含 P2P 直连；被控端 60 秒内自行停机，停采集、停直连、不再往外发一个字节）；
   - **想重新装回来的**：安装接口直接拒绝，粘贴多少次都没用。

> 撤销**按激活码原文**记，不按授权编号：编号会被续期复用（`HK-REL-0001` 续期还是
> `HK-REL-0001`），按编号撤销会误伤同编号的新码。所以删除只影响你删掉的那一条，
> 给同一个客户重新签发的**新码照常可用**。

**必须注意**：

- 「删除」要生效，前提是能连上中继服务器。状态列会明确区分
  「已删除（已同步）」与「**已删除（未同步到服务器！）**」；
  后者客户那边其实还能用到到期 —— 点「同步撤销名单」补推即可。
- 被控端**断网离线**时，本地缓存只认激活码里的到期时间；但它有一条**离线宽限**：
  连续 48 小时（默认，可在被控端 agent.json 里改）联系不上中继就会自行停机，连上后自动恢复。
  所以撤销 / 续期最多 48 小时一定生效。
- 「恢复」会把这条从服务器撤销名单里移除（清空撤销记录），之后它可以被重新安装。

### 需要管理令牌（2026-09 起）

- 安装、撤销、恢复、同步都要**管理令牌**（服务器 systemd 里的 `RC_ADMIN_TOKEN`）。
  2026-09 起管理页 `/admin` **不再收**发给客户的中继令牌 `RC_TOKEN` —— 那条随主控端分发包发出去了，
  不能当管理凭据；中继令牌继续用于被控端/主控端连线，与本工具无关。
- **直接粘进「令牌」框就行**：框里是明文，粘完能看见自己粘的是什么；粘上就记住（存在 `keygen-settings.json`）。
- 不想让旁边的人看见时勾「**隐藏**」，令牌会变成圆点；取消勾选又变回明文。
- **也可以让程序自己找**：启动时会自动去这几个位置找一条填上，找到并记住 ——
  `私钥目录\admin-token.txt` → `私钥目录\relay-token.txt` → `E:\tools\hk-admin-token.txt` → `E:\tools\hk-token.txt` → 程序目录
  （管理令牌优先；旧服务器的中继令牌文件仍兜底，但新管理页会拒绝它）；
  之后想再找一次就点「**读取令牌**」（只在令牌框为空时读）。
- 「安装入口」下面那行字会说明令牌的来路：`已填令牌：32 位，来自 <文件>` 或 `当前没有令牌：…`。
- 点「**清空**」把令牌和本机设置里存的那份一起清掉，**不会**被自动兜回来（想恢复就点「读取令牌」或重新粘）。
- 只读操作（刷新状态、读部署ID）**不需要**令牌。

### 导出

「导出 CSV」把整本台账导出成表格（Excel 可直接打开，含撤销状态与安装时间），适合留档对账。

## 三、常见问题

| 现象 | 怎么处理 |
|---|---|
| 状态栏说「找不到私钥文件」 | 用「选择…」指到 `private.pem`，或点「生成新密钥对」新建一套（新密钥必须重新编进中继与被控端） |
| 客户说装不上 | 先在这里「验证激活码」看是否本厂商签发；再确认绑定部署ID 与客户服务器一致；确认这条没被你删除 |
| 客户说忽然不能用了 | 看服务器 `/admin` 的状态：`expired` 是到期，`revoked` 是被删除，`clock_anomaly` 是服务器时间被回拨；「刷新状态」也能看到 |
| 到期了怎么续 | 直接签一条新码装上即可（编号可以沿用，方便对账）；想留长一点就把到期日期往后填 |
| 服务器进不去 | 授权失效时 `/admin` 仍然可以打开（就是为自救留的），令牌来自服务器上 `systemctl cat rcserver` 里的 `RC_TOKEN` |
| 撤销后客户还有反应 | 确认台账里显示的是「已同步」；被控端要联网至少一次（60 秒一轮）才会停机 |
