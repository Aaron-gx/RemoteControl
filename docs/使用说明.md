# 远程控制软件 · 使用说明

## 一、它是什么

默认（**共享模式**）：远程操作的就是被控电脑**当前已登录用户自己的桌面**，另外给这个桌面加一块
**虚拟外屏**（1920×1080，在物理屏右边）。远程看到的是这块外屏；把窗口从物理屏拖到外屏，远程就能看到并操作它——
同一个账户、同一份软件与文件（微信、浏览器、文件目录都是本机用户那一份），不需要在两台机器之间传数据。

> 早期还有一种**独立会话模式**（新建 `RemoteWorker` 用户 + RDP 回环会话）。**它已经不再提供了**：
> 那是另一个账户、另一份 profile，微信/浏览器/文件都跟本机管理员不共享，与本产品的形态相冲突。
> 安装向导里已经没有这个选项，被控端配置也会自动从旧方案迁回共享模式（启动日志会写明）。
> 下面表格右边一列仅用于理解历史差别。

| | 共享模式（默认，唯一形态） | 独立会话模式（已不再提供） |
|---|---|---|
| 远程看到 | 本机已登录桌面 + 虚拟外屏 | 单独的 RDP 会话桌面（并发会话） |
| 数据/软件 | 与本机用户**同一份**（同一账户、同一 profile） | 另一套（RemoteWorker 用户），不共享 |
| 键鼠 | 本机**独占自己的光标**；远端默认原生光标，本机在用时自动切"后台定向注入"，**互不抢、互不可见** | 两边各一套，互不干扰 |
| 需要被控端有人登录 | **是**（没人登录就没有可共享的桌面） | 否（可无人值守） |
| 依赖 | 只装虚拟外屏驱动 | 还要 RDPWrap + 新建用户 + 开 3389 |

三个部件：

| 部件 | 装在哪 | 作用 |
|---|---|---|
| **主控端 Viewer** | 你的电脑 | 看远程画面、点鼠标键盘、管理远程软件 |
| **中继服务器** | 公网服务器（当前：香港 202.60.232.209:8080） | 让双方找到彼此（双方都只做出站连接，不用公网 IP/端口映射） |
| **被控端 Agent** | 被控制的电脑 | 采集画面、注入键鼠、执行打开/关闭软件 |

数据流：`主控端 ⇄ 中继 ⇄ 被控端`。视频/键鼠/剪贴板都经中继透传（带共享令牌鉴权）。

## 二、三个部件怎么起

**主控端**：双击桌面「远程控制-主控端」或 `E:\RemoteControl\start-viewer.cmd`。
服务器地址与连接口令已预置，打开就能用：点「刷新」会在被控端下拉框里列出在线机器，
**只有一台在线时自动连上**（多台在线时自己选一台再点「连接」）。
左侧「已安装软件」和画面都是**连上之后**才有的——没连上时面板里会写明原因（未连接 / 被控端不在线）。

**中继服务器**：已注册开机自启（systemd `rcserver`）。管理命令：
```bash
/opt/rcserver/rcctl status          # 服务器状态与部署ID
/opt/rcserver/rcctl logs 50         # 看日志
/opt/rcserver/rcctl restart         # 重启
```

**被控端**：已注册开机自启（计划任务 `RemoteControlAgent`，登录时以最高权限启动）。
手动启动/停止见 `E:\RemoteControl\README.md`。

## 三、怎么给别人的电脑装被控端

**只要一个文件**：`被控端安装程序.exe`（约 200 MB，里面已经把被控端程序、驱动、安装脚本都打包好了）。

1. 把这**一个 exe** 拷到要被人远程操作的那台电脑（U 盘/网盘都行）
2. **双击它** → 标准安装向导，**下一步 → 下一步 → 安装中 → 完成**（不需要填任何信息）：
   欢迎页（点「下一步」）→ 选择安装位置（点「开始安装」）→ 自动安装 → 完成页显示结果
   - 服务器地址与连接口令已经在打包时写进去了，放在「高级设置」里，正常安装用不到
   - 安装位置默认 `E:\RemoteControl\agent`，可改
   - 选项默认：虚拟外屏 ✓、自动启动 ✓、Defender 排除 ✓、**独立会话模式 ✗**（不勾 = 共享模式：
     远程操作本机当前桌面 + 外屏，软件与数据跟本机用户是同一份）
3. 会申请管理员权限（装驱动/计划任务需要）→ 自动装完（约 1~2 分钟）
4. **装完会直接告诉你结果**：
   - **已连上服务器** → 并显示这台电脑的 **AgentId**（形如 `AURA-XXXXXXXX`）：
     主控端点「刷新」，在列表里选这个 AgentId 即可连接
   - **连不上服务器** → 写明卡在哪一步、怎么改（网络被挡 / 服务器不可用）

被控端运行后，托盘图标悬停会显示 `已连接服务器` / `未连接服务器（会自动重试）`；
主控端连上后，状态栏会显示**这台电脑的名字与系统**（被控端主动上报），一眼知道连的是哪台。
共享模式下还会显示 `WIN-XXXX（用户名）Windows 11 ...`，方便确认"这是谁的那台、哪个账户"。

**共享模式的限制**（用之前先知道）：
- 被控端必须**保持有人登录**（锁屏/UAC 弹窗期间主控端看不到画面、也点不动，主控端画面会写明原因）；
- **鼠标**：本机用户永远独占自己的光标、永远不会被打断；远端默认也用原生光标（悬停/拖拽/原生右键菜单都完整），
  本机用户一旦开始用鼠标，远端会自动切换成「把事件直接投给窗口」的方式继续操作，不碰本机用户的光标。
  这段**两人同时用**的时间里有几个已知代价：远端侧的原生右键菜单、依赖鼠标捕获的拖拽、DirectInput 类的游戏可能失效；
  本机用户一停手（约 1 秒）远端就自动恢复原生光标。
- **键盘**：同一时刻只有一个窗口能收到键盘（Windows 的限制）。本机用户正在打字时，远端的按键会被**暂时忽略**，
  并在主控端提示原因 —— 这是为了避免把字打进本机用户正在编辑的文档。

**无人值守批量安装**（可选）：
```powershell
被控端安装程序.exe --silent --dir E:\RemoteControl\agent
```
（`--multi-session` 只对旧的自制安装器还有效，属于"不推荐"的历史路径；正式安装程序已不再提供该模式。）
退出码 0 = 成功。重复安装是安全的（不会丢 AgentId、不会重复装驱动）。

## 四、主控端界面

```
┌──────────────────────────────────────────────────────────┐
│ 服务器 [ws://...:8080/ws]  被控端 [ID ▾] 刷新 连接  使用说明 │
├───────────────┬──────────────────────────────────────────┤
│ 已安装软件 53项 │                                          │
│ ⚪ 记事本      │        远程电脑的实时画面                  │
│ ⚪ 计算器      │   （鼠标点进来就能操作远程电脑）            │
│ 🔵 微信        │                                          │
│  右键 → 打开   │                                          │
│  右键 → 关闭   │                                          │
├───────────────┴──────────────────────────────────────────┤
│ 🟢 已连接 │ 延迟: 39ms │ 分辨率: 1920×1080 │ FPS: 25 │ 码率 │
│ 连接: 直连                                             │
└──────────────────────────────────────────────────────────┘
```
- 「连接: 直连 / 中继」就是当前视频走的链路
- 连接栏里的 **链路** 下拉框可以手动选链路（见第五节）
  （编号/客户/到期时间/被控端是否已停机/服务器续期入口）
- 点「**使用说明**」按钮打开的窗口会**按 Markdown 排版**显示本文档（标题、表格、代码块都正常渲染），
  左上角 A- / A+ 可调字号；命令行 `Viewer.exe --help-doc` 也能单独打开它
- 🔵 = 该软件在被控端**已运行**；⚪ = 未运行
- **右键软件 → 打开**：在被控端启动它（共享模式下窗口会**自动摆到虚拟外屏上**，主控端立刻能看到）
- **右键软件 → 关闭(退出)**：直接结束该进程
- 画面区域内直接用鼠标键盘操作被控端；共享模式下就是操作**对方那个桌面（虚拟外屏）**。
  远端光标由主控端自己绘制，所以**本机屏幕上永远不会出现远端的光标**；本机用户一动自己的鼠标，
  远端会自动切换操作方式（见第三节），两边互不干扰
- 想让远程看到本机正在用的某个窗口：把它**拖到外屏**（物理屏右边那块 1920×1080）即可
- 远程复制文件后，状态栏提示「📋 远程文件可粘贴」，在画面内按 **Ctrl+V** 即下载到本地
  下载目录：`E:\RemoteControl\Downloads`（可在 `viewer.json` 的 `DownloadDir` 改）
- 剪贴板文本双向同步：远程 Ctrl+C → 本地 Ctrl+V 可用；本地复制 → 远程 Ctrl+V 可用

## 五、P2P（直连）说明

**默认情况下视频走香港中继**；只要网络条件允许，软件会**自动改用点对点直连（P2P）**，
连不上就自动回落中继，**用户不需要任何操作**。

为什么需要中继：双方通常都在 NAT 后面，谁都不知道对方的公网地址，必须有一个双方都可达的点
先"互相介绍"（交换地址）＋ 兜底。控制指令、剪贴板、文件仍然走中继（流量很小），
**只有占带宽的视频流会改走直连**。

| 级别 | 适用场景 | 做法 | 状态 |
|---|---|---|---|
| **L1 直连** | 两台电脑在**同一局域网**；或一方有公网 IP / 已在路由器上映射 47890 端口 | 中继只用来交换地址，视频直接点对点 | **已上线（实测通过）** |
| **L2 打洞** | 双方都在家庭宽带 NAT 后、且路由器不支持 UPnP | UDP 打洞（QUIC 承载） | 未实现（规划中） |
| **L3 中继** | 对称 NAT / 企业防火墙 / 直连失败 | WebSocket 中继 | **已上线** |

### 怎么选"走直连"还是"走中继"

连接栏的 **链路** 下拉框（选择会被记住，下次启动沿用）：

| 选项 | 行为 | 什么时候用 |
|---|---|---|
| **自动（优先直连）** | 能直连就直连，连不上自动回落中继 | 默认，推荐 |
| **仅中继（经服务器）** | 视频一律经服务器中转，不尝试直连 | 想固定走服务器（例如排查网络、强制省对端上行） |
| **仅直连（P2P）** | 视频只走直连；直连建不起来就没有画面 | 明确要求视频不经服务器时（**注意**：此时若对端无公网可达地址，会一直没画面） |

> 三种模式下**控制指令、剪贴板、文件、软件列表始终走中继** —— 中继是信令与兜底通道，关不掉。
> 想临时验证"到底走没走服务器"，选「仅中继」再看服务器 `iftop` 有流量、选「仅直连」看服务器只剩控制流量。

### 怎么看到当前是"直连"还是"中继"

| 位置 | 看到什么 |
|---|---|
| **主控端状态栏** | `连接: 直连（被控端 直连 1234 帧/5678KB，中继 0 块）` —— 帧数是**被控端**统计的，"中继 0 块"说明视频真的没经过服务器 |
| **被控端日志** | `P2P 直连已建立：x.x.x.x:xxxx（视频改走直连…）`；每 5 秒的诊断行 `直连=已建立(x.x.x.x, 1234帧/5678KB)` |
| **香港服务器** | `iftop -i ens17` 或 `vnstat -l`：直连生效时**看不到视频流量**（只剩控制指令），这是省流量最直接的证据 |

### 直连打不通怎么办（跨网络时）

家用路由器默认都是 NAT，跨网络直连需要路由器愿意自动开端口（UPnP）：

1. 登录路由器后台，**打开 UPnP**（多数路由器默认开启；有些叫「UPnP / NAT-PMP」）
   → 被控端日志会出现 `P2P 公网候选：x.x.x.x:47890`
2. 路由器不支持/不让开 UPnP：**手动做端口映射**，把外网 TCP **47890** 映射到被控端内网 IP 的 47890，
   然后在被控端 `config\agent.json` 里填 `"DirectLinkPublicAddress": "你的公网IP:47890"`，重启被控端
3. 都不方便：**不用管**，会自动走中继，功能完全一样（只是视频要经过香港服务器）

端口冲突时可改 `config\agent.json` 的 `DirectLinkPort`（改完记得同步改端口映射）。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| **连不上服务器（最全的排查）** | 在出问题的那台电脑上**双击 `连接自检.cmd`**：依次检查 配置 → 地址 → 端口 → 健康检查 → 令牌 → 在线列表 → WebSocket 握手，并直接给出失败原因和改法（同时留 `selfcheck-*.log`） |
| 被控端连不上服务器 | 服务器有三个端口在跑：**8080 / 443 / 8443**，被控端连不上 8080 时会**自动改用 443、8443**（不用改任何配置）。三个都连不上才是网络被挡 → 用手机热点验证一次 |
| 主控端提示「无法获取被控端列表」 | 先跑 `连接自检.cmd`；若报 401 说明令牌不一致（两端 `AgentToken` 要与服务器令牌完全一致，改完重启程序） |
| 主控端提示「被控端不在线」 | 确认被控端电脑已开机且程序在运行；被控端日志见 `E:\RemoteControl\agent\logs`。共享模式下**没人登录也会显示不在线**（没有可共享的桌面） |
| 界面看不清/字太小 | 使用说明窗口左上角 A- / A+ 调字号；主控端整体是深色主题，不随 Windows 浅色模式变白 |
| 提示 `unauthorized` | 令牌不一致：被控端/主控端配置里的 `AgentToken` 要与服务器 `RC_TOKEN` 相同 |
| 主控端提示「被控端正在显示 UAC 提权窗口或锁屏」 | 这是共享模式的正常现象：被控端弹了提权框/锁屏，Windows 切到安全桌面，采集不到也点不动。**在被控端点掉那个弹窗**（或解锁）就自动恢复 |
| 画面黑屏（共享模式） | 先看主控端画面里的文字提示：写了 UAC/锁屏就按上面处理；什么都没写就看被控端日志 `worker-*.log` 有没有 `不在输入桌面上`、`WGC 会话` 异常 |
| 画面黑屏（独立会话模式） | 被控端会话掉线 → 看护会在 20 秒内自动重建（含自动确认 Windows 的安全警告框）；查日志有没有 `RemoteWorker 会话已就绪且活动` 与 `Worker 就绪` |
| 打开的应用是黑的/卡住 | 该应用在被控端渲染不出来（模拟器、游戏、播放器对显卡/独占全屏有要求）。换一台有物理显卡的被控端，或改用独立会话模式试；被控端日志里会留下 `把 xxx 窗口移到外屏` 那一步 |
| 一直显示「连接: 中继」 | 跨网络时对端没有可达的公网地址：开路由器 UPnP，或手动映射 47890 并填 `DirectLinkPublicAddress`（见第五节） |
| 远程打字没反应 | 远程会话的输入桌面异常（例如 RDP 客户端被最小化）；看护会自动纠正 |
| 想改分辨率/码率 | 改被控端 `agent.json` 的 `VirtualDisplayWidth/Height`、`FrameRate`、`BitrateKbps` |
