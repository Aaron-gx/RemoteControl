# 远程控制软件 · 使用说明

## 一、它是什么

默认（**共享模式**）：远程操作的就是被控电脑**当前已登录用户自己的桌面**，另外给这个桌面加一块
**虚拟外屏**（1920×1080，在物理屏右边）。远程看到的是这块外屏；把窗口从物理屏拖到外屏，远程就能看到并操作它——
同一个账户、同一份软件与文件（微信、浏览器、文件目录都是本机用户那一份），不需要在两台机器之间传数据。

**热更新**：被控端和主控端都支持自动更新——被控端在空闲时自动下载并安装新版本（不需要人去机器旁边），
主控端有新版本时状态栏会提示"点击下载"。

> 早期还有一种**独立会话模式**（新建 `RemoteWorker` 用户 + RDP 回环会话）。**它已经不再提供了**：
> 那是另一个账户、另一份 profile，微信/浏览器/文件都跟本机管理员不共享，与本产品的形态相冲突。

| | 共享模式（默认，唯一形态） |
|---|---|
| 远程看到 | 本机已登录桌面 + 虚拟外屏 |
| 数据/软件 | 与本机用户**同一份**（同一账户、同一 profile） |
| 键鼠 | 本机**独占自己的光标**；远端默认原生光标，本机在用时自动切"后台定向注入"，**互不抢、互不可见** |
| 需要被控端有人登录 | **是**（没人登录就没有可共享的桌面） |
| 自动更新 | **是**（空闲时自动升级，新版本崩溃自动回滚旧版） |

三个部件：

| 部件 | 装在哪 | 作用 |
|------|--------|------|
| **主控端 Viewer** | 操作者的电脑 | 看远程画面、点鼠标键盘、管理远程软件 |
| **中继服务器** | 公网服务器 | 让双方找到彼此 + 热更新分发 |
| **被控端 Agent** | 被控制的电脑 | 采集画面、注入键鼠、执行打开/关闭软件 |

## 二、三个部件怎么起

**主控端**：双击安装程序装好 → 点「刷新」列出在线机器 → 选一台 → 点「连接」。

- 服务器地址与口令已预置，装完即用
- 左侧软件列表第一项是**「此电脑」**，右键打开后窗口直接在副屏显示（不在主屏闪）
- 远程复制文件**或文件夹**后在画面内 **Ctrl+V** 即下载到本地（文件夹会自动解压）
- 有新版本时状态栏会显示"⬆ 有新版本"，点击即可下载

**中继服务器**：已注册开机自启。热更新管理页：`http://<服务器>:18080/admin/update?token=<管理令牌>`

**被控端**：已注册开机自启（计划任务 `RemoteControlAgent`，登录时以最高权限启动）。
装完右下角**不显示**托盘图标（客户要求）；需要时改 `agent.json` 的 `ShowTrayIcon=true` 重启。

## 三、怎么给别人的电脑装被控端

**只要一个文件**：`虚拟网服务-安装包.zip`（约 76 MB，含安装程序 + 预置口令）。

1. 把安装程序拷到目标电脑
2. **双击** → 标准向导 → 完成（正常情况不需要填任何信息）
3. 装完自动上线，主控端点「刷新」就能看到

## 四、远程操作

### 打开软件
- 左侧列表**右键** →「打开」→ 窗口自动摆在副屏上（主屏不会有任何闪现）
- 置顶项**「此电脑」**：打开资源管理器"此电脑"，窗口直接在副屏

### 复制粘贴
- **文本**：远程 Ctrl+C → 主控端 Ctrl+V（双向自动同步）
- **文件**：远程复制文件 → 主控端画面内 Ctrl+V → 自动下载到本机
- **文件夹**：远程复制文件夹 → 主控端画面内 Ctrl+V → 自动解压成文件夹到本机

### 画面切换
- 工具栏「画面」下拉：
  - **副屏（省流量）**：默认，只看虚拟外屏 1080p
  - **主屏**：看被控端物理主屏（只读，点击不打扰机器前的人；点击窗口可搬到副屏）

## 五、常见问题

| 现象 | 处理 |
|------|------|
| 主控端显示"被控端不在线" | 中继未启动或被控端未运行；查 `api/agents` 与被控端日志 |
| 画面黑屏 | UAC 提权窗口/锁屏期间（安全桌面）看不到，等它消失自动恢复 |
| 远程键鼠无反应 | 被控端有人正在用键鼠（远端按键暂时忽略，对方停手自动恢复） |
| 被控端不自动更新 | 检查 `agent.json` 的 `AutoUpdateEnabled`；看日志中"更新"相关条目 |
| 主控端"此电脑"打开后主屏闪 | 确认被控端版本 ≥ 1.2.5（主控端状态栏看 AgentVersion） |

## 六、热更新（自动升级）

被控端**不需要人去机器旁边升级**：
- 每 6 小时自动检查一次新版本
- 验证签名 → 下载 → 等没人远程连接时自动安装
- 新版本起来后 90 秒内没"报平安"会自动回滚到旧版

主控端**只提示、不自动装**：连接时查一次，有新版在状态栏显示"点击下载"。

厂商发布新版本：LicenseKeygen →「更新签名」页 → 一键发布。
