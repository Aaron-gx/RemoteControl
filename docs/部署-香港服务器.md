# 部署中继服务器到香港服务器

> 架构：`主控端 Viewer` ⇄ `中继服务器（香港）` ⇄ `被控端 Agent`
> 中继只做两件事：WebSocket 透传 + 剪贴板文件暂存（10 分钟自动清理）。它对双方都必须可达，
> 所以放在公网服务器上；主控端与被控端都可以在任意 NAT 后面（只做出站连接）。

## 0. 为什么必须由主控端/被控端主动外连

主控端和被控端都只**主动连接**中继，不需要公网 IP、不需要端口映射、不需要改路由器 —— 这是
"随时能连上别人电脑"的关键。中继服务器是唯一需要公网可达的角色。

## 1. 目录与端口

| 项 | 值 |
|---|---|
| 监听 | `0.0.0.0:8080`（可用 `-addr` 改） |
| WebSocket | `/ws?role=agent&id=<被控端ID>&token=<令牌>`、`/ws?role=viewer&target=<被控端ID>&token=<令牌>` |
| 在线列表 | `GET /api/agents?token=<令牌>` |
| 文件暂存 | `POST /api/upload`、`GET /api/download/{fileId}`（同样要令牌） |
| 健康检查 | `GET /healthz`（不需要令牌） |
| 数据目录 | `-data`，默认 `./data`；**不要**把日志写到这个目录（会被当暂存文件清理） |

## 2. 一键部署（Linux，推荐）

服务器上执行（需要 root）：

```bash
# 1) 把二进制和脚本传上去（在你自己的电脑上执行）
scp RemoteControl/build/server/rcserver-linux-amd64  root@<服务器IP>:/tmp/
scp RemoteControl/scripts/deploy-relay.sh             root@<服务器IP>:/tmp/

# 2) 在服务器上安装
ssh root@<服务器IP>
sudo bash /tmp/deploy-relay.sh --binary /tmp/rcserver-linux-amd64 --port 8080
```

脚本会自动：装到 `/opt/rcserver` → 建 systemd 服务（**令牌写在服务文件里，不出现在进程命令行**）
→ 开机自启 → 放行防火墙（ufw/firewalld/iptables）→ 健康检查 → 打印令牌与配置片段。

**记得在云厂商控制台的「安全组」里放行 8080/tcp**（脚本无法代劳）。

也可以从 Windows 一条命令完成（需要免密 SSH 或指定私钥）：

```powershell
# 免密（推荐：先 ssh-keygen + 上传公钥）
powershell -ExecutionPolicy Bypass -File RemoteControl\scripts\deploy-relay-remote.ps1 -Host <服务器IP> -User root
# 指定私钥
powershell -ExecutionPolicy Bypass -File RemoteControl\scripts\deploy-relay-remote.ps1 -Host <服务器IP> -User root -KeyFile $env:USERPROFILE\.ssh\rc_relay
```

如果服务器是 **Windows**：把 `build\server\rcserver-windows-amd64.exe` 传上去，然后
`rcserver.exe -addr :8080 -data D:\rcdata -token <令牌>`，再注册一个计划任务开机自启（参考
`scripts/setup-launchers.ps1`）。arm64 Linux 用 `rcserver-linux-arm64`。

## 3. 共享令牌（重要）

中继默认**要求令牌**：`-token <值>` 或环境变量 `RC_TOKEN`。

- 不设令牌 = 任何人只要猜到被控端 ID 就能连上这台被控端（**只允许在回环/内网测试时使用**）
- 设了令牌 = 主控端与被控端必须携带**同一个**令牌，服务器用常量时间比较校验
- 令牌出现在：WebSocket URL 的 `token=` 参数、文件接口的 `token=` 参数 / `X-RC-Token` 头 / `Authorization: Bearer`

三处配置必须一致：

| 组件 | 文件 | 字段 |
|---|---|---|
| 被控端 | `E:\RemoteControl\agent\config\agent.json` | `AgentToken` |
| 主控端 | `E:\RemoteControl\viewer\config\viewer.json` | `AgentToken` |
| 服务器 | systemd 服务文件的 `Environment=RC_TOKEN=...` | — |

**管理令牌（`RC_ADMIN_TOKEN`，2026-09 起必须配置）**：授权管理页 `/admin` 只认它，
不再接受 `RC_TOKEN` —— 中继令牌随主控端分发包（`viewer-defaults.txt` 的 `Token=`）发给了客户，
拿它开管理页等于把"装码/撤销/恢复激活码"交给客户（已撤销的码能被恢复、旧的长有效期码能盖掉新码）。

| 组件 | 配置 |
|---|---|
| 服务器 | systemd 服务环境 `Environment=RC_ADMIN_TOKEN=...`（或启动参数 `-admin-token`） |
| 厂商上位机 | `E:/tools/hk-admin-token.txt`（LicenseKeygen 自动读取；私钥旁 `admin-token.txt` 亦可） |

要求与注意：必须与 `RC_TOKEN` **不同**；泄露了就在服务器上换一条并 `systemctl restart rcserver`
（客户端只认 `RC_TOKEN`，重启不影响在线连接）。未配置时 `/admin` 仅限服务器本机访问。

## 4. 两端怎么改指向香港服务器

被控端 `agent.json`：
```json
{
  "ServerUrl":     "ws://<服务器IP>:8080/ws",
  "FileServerUrl": "http://<服务器IP>:8080",
  "AgentToken":    "<令牌>"
}
```
主控端 `viewer.json`：
```json
{
  "ServerUrl":     "ws://<服务器IP>:8080/ws",
  "FileServerUrl": "http://<服务器IP>:8080",
  "AgentToken":    "<令牌>",
  "TargetAgentId": "<被控端ID>"
}
```
被控端改完重启一次（`Agent.Coordinator.exe`，托盘退出再启动，或 `deploy-quick.ps1`）。
主控端改完重开 `Viewer.exe`，点「刷新」就能看到在线的被控端。

> 想要 `wss://`（TLS）：需要域名 + 证书。最省事的做法是前面挂一个 Nginx/Caddy 反代
> `location /ws { proxy_pass http://127.0.0.1:8080; proxy_http_version 1.1;
> proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade"; }`，
> 然后两端把地址写成 `wss://域名/ws` 与 `https://域名`。

## 5. 带宽与体验估算

- 视频默认 4 Mbps/路（`BitrateKbps` 可调，2 Mbps 也够看）
- 典型使用：每路 ~4 Mbps 下行 + ~0.1 Mbps 上行（键鼠/剪贴板）
- 香港/日本机房到国内的往返延迟通常 30~80ms → 远程操作手感可接受（帧率 15~30fps）
- 若延迟敏感，见 `docs/P2P方案.md`（直连优先 + 中继兜底）

## 6. 排障

| 现象 | 检查 |
|---|---|
| 主控端「被控端不在线」 | `curl "http://<IP>:8080/api/agents?token=<令牌>"`；看被控端日志 `E:\RemoteControl\agent\logs\coordinator-*.log` |
| 连不上 `ws://` | 云安全组 + 服务器防火墙是否放行 8080；`curl http://<IP>:8080/healthz` |
| 401 unauthorized | 两端令牌与服务器 `RC_TOKEN` 是否一致 |
| 画面卡 | 降 `BitrateKbps`/`FrameRate`；或看服务器带宽是否跑满 |
| 服务器重启后服务没起 | `systemctl status rcserver`；`journalctl -u rcserver -n 50` |


## 八、升级中继到最新构建（含授权管理页）

中继程序更新只需替换二进制并重启服务（数据目录 `/var/lib/rcserver` 保留，部署ID与授权不受影响）：

```powershell
# 本机（Windows）一条命令，经 hk.py 走本机代理上传并重启：
RemoteControl\scripts\update-relay.cmd
## 多端口监听（443 / 8443）：对付"某些网络封了 8080"

被控端 / 主控端内置了**同主机端口自动重试**：主地址连不上就依次试 `443`、`8443`
（见 `src/Agent/Agent.Coordinator/RelayClient.cs` 的候选端点列表），所以服务端多听两个端口，
那些封了 8080 的机器**不用改任何配置**就能连上。

服务端的 `-addr` 支持**重复指定**（`main.go` 里用 `flag.Func` 收集）：

```bash
/opt/rcserver/rcserver -addr :8080 -addr :443 -addr :8443 -data /var/lib/rcserver
```

香港服务器是通过 systemd drop-in 加的（**不要**直接改 `/etc/systemd/system/rcserver.service`，
升级/重装脚本会覆盖它）：

```bash
mkdir -p /etc/systemd/system/rcserver.service.d
cat > /etc/systemd/system/rcserver.service.d/ports.conf <<'EOF'
[Service]
ExecStart=
ExecStart=/opt/rcserver/rcserver -addr :8080 -addr :443 -addr :8443 -data /var/lib/rcserver
EOF
systemctl daemon-reload && systemctl restart rcserver
ss -lntp | grep -E ':(8080|443|8443)\b'
```

> 注意 `ExecStart=` 那一行**不能省**：systemd 要求先清空原值才能覆盖（否则报
> "ExecStart 只能指定一次"）。

**回滚**：`rm /etc/systemd/system/rcserver.service.d/ports.conf && systemctl daemon-reload && systemctl restart rcserver`

**容错设计**：三个端口各自独立绑定，某个端口失败只记一行 `warning`（不影响其它端口）；
只有**全部**绑不上才退出。这样"443 被别的程序占用"不会把 8080 一起拖down。

> **本机 SSH 到香港服务器的前提（实测）**：本机到该 IP 的 **22 端口在"直连"下会被链路重置**
> （TCP 握手成功、随后被注入 RST），必须让代理客户端处于 **规则/全局** 模式把 22 端口走节点；
> HTTP 8080 直连正常，所以 `curl /healthz`、`/api/license` 不受影响。
> 排查手法：`curl -s http://127.0.0.1:39798/configs`（Clash Meta 外部控制口）看 `mode`；
> 改模式：`curl -X PATCH -d '{"mode":"rule"}' http://127.0.0.1:39798/configs`。
> 注意 Git Bash 下执行 `hk.py put` 要带 `MSYS_NO_PATHCONV=1`，否则远端路径会被翻译成 Windows 路径。

> **升级前留回滚点**：`cp -a /opt/rcserver/rcserver /opt/rcserver/rcserver.bak-$(date +%Y%m%d-%H%M%S)`，
> 出问题就覆盖回去重启（数据目录不用动）。2026-09-21 那次升级的回滚点是 `rcserver.bak-20260921-133116`。

```

等价的服务器侧命令：

```bash
systemctl stop rcserver
cp /tmp/rcserver-new /opt/rcserver/rcserver && chmod +x /opt/rcserver/rcserver
systemctl start rcserver
/opt/rcserver/rcctl status
```

更新后可用的新入口：

| 入口 | 说明 |
|---|---|
| `http://<服务器>:8080/admin?token=<管理令牌>` | **授权管理页**：看状态/剩余天数、粘贴激活码安装/续期、卸载授权（排障）。授权过期后仍可访问 |
| `http://<服务器>:8080/api/license` | 机器可读的授权状态（排障/上位机自动读取部署ID用） |
| `/opt/rcserver/rcctl status` / `install "<码>"` | 命令行方式，功能同上 |

> 注意：管理页能改授权状态，等同于中继的管理入口，务必带上令牌使用，不要把带令牌的链接外发。
